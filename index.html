How it works
Three steps. Zero friction.
No app to download, no signup form, no onboarding wizard.
01

Add the bot

Add @grumps to your WhatsApp group. That's it. The workspace is created automatically.

02

Talk normally

Type TODO: to add tasks, NOTE: to pin info, or @mention the bot for anything else. Your group keeps chatting.

03

Open the workspace

When you need the full picture — todos, notes, files, history — open your private web workspace. Phone verification keeps it secure.

Features
Chat when it's quick. Web when it's not.
Everything you add from chat appears in the workspace. Everything you do on the web syncs back to the group.
☐

Todos that stick

Add todos from chat with natural language. Assign people, set deadlines, add priorities. Reply "done" to a task card to complete it. View them as a list or kanban board on the web.

assignments deadlines priorities kanban
¶

Notes that don't get buried

Pin important info with NOTE: in the chat. WiFi passwords, house rules, contact details — always findable. Edit with a full Markdown editor on the web.

markdown rich editor full-text search
◰

Files in one place

Reply @grumps store to any image or document in the chat. It's saved, named, and previewable on the web. No more scrolling back through months of messages.

PDF preview image gallery drag & drop
⏰

Reminders that fire

"@grumps remind @Bob tomorrow 9am take out the trash." Recurring reminders too. The bot sends a WhatsApp message when it's time. No app notifications to ignore.

one-time recurring natural language
◫

A real web workspace

Not a dashboard with three stats. A full workspace with todos, notes, files, activity history, and settings. Accessible only to verified group members via WhatsApp OTP. Dark mode, search, exports, mobile-friendly.

OTP auth member-only mobile-ready dark mode export
